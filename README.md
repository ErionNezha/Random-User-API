# Gjenerator Profili

Gjenero profile të rastësishme shqiptare me pamje JSON — gjithçka në browser, pa server.

## ✨ Veçoritë

- 🎲 Gjeneron profile të rastësishme shqiptare: ~20 emra × ~20 mbiemra, qytete (Tiranë, Durrës, Prishtinë…), profesione
- 👤 Avatar rrethor me iniciale + gradient ngjyre nga hash-i i emrit
- 📧 Email, 📱 telefon (+355 6X XXX XXXX), 🎂 datëlindje, 🪪 ID — të gjitha fiktive
- { } Pamje JSON me ngjyrosje sintakse manuale
- 📋 Buton "Kopjo JSON" (clipboard me fallback)
- 🕘 Historik: 5 profilet e fundit si chips klikuese
- 🧪 100% në browser — të dhëna fiktive, asnjë server
